# Historical Artifact Archive: Legacy Web Index

This directory contains the original prototype assets created during the initial compilation and architectural brainstorming of the campaign.

## File Registry

### 📄 `oldindex.html`
- **Description:** The first working draft of the project's public landing page.
- **Historical Significance:** This asset marks the conceptual baseline of the archive. It was deployed when the project was focused entirely on isolated Reddit infrastructure failures, preceding the expansion into multi-platform tracking (including X/Twitter criticisms), institutional suppression logs, and dark-theme configurations.

## Structural Evolution
Unlike the current production-ready `index.html` which features deep-dive multi-page routing, custom dark theme styles, and advanced script injections, this legacy asset used a light-mode styling profile to display the project's initial core thesis: **the absolute contradiction of an automated verdict posing as an unaided human decision.**

It is preserved here permanently to document the early development workflow and timeline of the repository.
